# Finance Bro

A lightweight, mobile-first budgeting web app for GitHub Pages.

## Files
- `index.html`
- `manifest.json`
- `icon-180.png`
- `icon-512.png`

## Deploy on GitHub Pages
Upload all four files to the root of your repository, commit them to `main`, then set GitHub Pages to deploy from `main` and `/(root)`.

On iPhone, open the Pages URL in Safari, tap Share, then **Add to Home Screen**.

## Data
Finance Bro stores your data locally on the device/browser. Use **Settings → Backup Finance Bro** regularly. CSV export is also included for Excel.

## Note
Charts use Chart.js from a CDN, so chart rendering requires internet access. All of your Finance Bro data itself stays local.
